АРХИТЕКТУРА
================================================================================

  Clean Architecture (Flutter):
  ─────────────────────────────
  UI (Widgets) → BLoC (State) → Repository → DataSource → Isar / Remote API
                                                  ↕
                                            Sync Engine

  Ключевые принципы:
  • Offline-first: данные сначала в Isar, затем синхронизация с сервером
  • Sync Engine: очередь операций, conflict resolution (last-write-wins)
  • Модульный backend: auth, products, sales, finances, staff — отдельные модули
  • WebSocket: real-time обновления POS, инвентаризации, остатков

  Структура Flutter-проекта:
  lib/
  ├── core/          — constants, errors, network, theme, utils
  ├── data/          — datasources (local/remote), models, repositories, sync/
  ├── domain/        — entities, repository interfaces, usecases
  ├── presentation/  — blocs, pages, widgets
  └── l10n/          — app_ru.arb, app_tg.arb, app_uz.arb

  Структура NestJS-проекта:
  src/
  ├── common/        — decorators, guards, filters, interceptors, pipes
  ├── config/        — database, redis, app config
  ├── modules/       — auth, users, stores, products, sales, finances,
  │                    customers, suppliers, inventory, loyalty, staff,
  │                    sync, notifications, subscriptions
  ├── jobs/          — BullMQ processors (reports, notifications, sync)
  └── prisma/        — schema.prisma, migrations/

  База данных (PostgreSQL + Prisma):
  • 20+ моделей: users, stores, products, categories, sales, sale_items,
    customers, suppliers, expenses, staff, shifts, inventory, loyalty, sync_logs
  • Enum-типы: StoreCategory, Currency, PaymentType, StaffRole, SyncStatus
  • Индексы на часто запрашиваемых полях (store_id + created_at, barcode, sku)

  Что разрабатывается:
  ────────────────────
  • Sync Engine: двусторонняя синхронизация Isar ↔ PostgreSQL
    - Очередь операций (sync_queue) с retry и exponential backoff
    - Conflict resolution: last-write-wins для полей, merge для количеств
    - Batch sync: пакетная отправка при восстановлении связи
    - WebSocket-уведомления об изменениях с других устройств
  • Финансовый дашборд: доходы, расходы, прибыль за период
  • CRUD расходов: категории (аренда, ЗП, транспорт и др.), повторяющиеся
  • Калькулятор доставки: расчёт стоимости доставки клиенту
  • Мультивалютность: TJS/USD/RUB, ручной курс обмена
  • Финансовый отчёт: PDF-генерация, отправка на email
  • Калькулятор закята (F-FIN-006):
    - Автоматический подсчёт: товарные остатки + наличные + дебиторка
    - Личное имущество: банковские счета, золото, транспорт, недвижимость
    - Множественные объекты в каждой категории с редактированием
    - Вычеты: кредиторка + личные долги
    - Нисаб (порог 85г золота), хавль (лунный год), ставка 2.5%
  • CRUD клиентов: контакты, история покупок, баллы лояльности
  • Управление долгами: клиентские долги, частичные оплаты, напоминания
  • CRUD поставщиков: контакты, привязка к товарам, долги
