## 1. Какие данные мы собираем

### Данные аккаунта
- Имя и фамилия
- Номер телефона (+992)
- Адрес электронной почты (необязательно)

### Данные магазина
- Название и адрес магазина
- Информация о товарах, продажах, расходах
- Данные о клиентах и поставщиках (имя, телефон)
- Данные о сотрудниках (имя, роль, рабочие часы)

### Данные устройства
- Модель устройства и версия ОС (для технической поддержки)
- Push-уведомления: токен устройства (Firebase Cloud Messaging)

### Данные Bluetooth
- Приложение использует Bluetooth для подключения к чековому принтеру
- Мы не собираем и не передаём данные Bluetooth-устройств

### Данные камеры
- Камера используется для сканирования штрихкодов товаров — изображения штрихкода не сохраняются и не передаются
- Камера или галерея используется для съёмки фотографий товаров и квитанций об оплате подписки (см. раздел «Загруженные изображения»)

### Загруженные изображения
- Фотографии товаров (выбираются из галереи или снимаются через камеру) хранятся вместе с карточкой товара на наших серверах и видны только владельцу магазина и его сотрудникам
- Фотографии квитанций об оплате подписки загружаются для проверки администратором; хранятся пока активна подписка и удаляются вместе с аккаунтом
- Изображения передаются по зашифрованному каналу (HTTPS); содержимое квитанций видно только администратору сервиса

### Диагностические данные (отчёты о сбоях)
- При сбое приложения автоматически отправляется отчёт через сервис **Sentry** (sentry.io)
- В отчёте передаются: тип ошибки, stack trace, версия приложения, модель устройства и версия ОС
- Также передаётся внутренний идентификатор вашего аккаунта — случайный номер, по которому нельзя узнать, кто вы. Он нужен, чтобы понять, скольких пользователей затронул сбой
- **НЕ передаются:** ваше имя, номер телефона, адрес электронной почты, содержимое экранов, токены авторизации, бизнес-данные магазина (товары, продажи, клиенты)
- Эти данные используются только для диагностики и исправления ошибок и хранятся не более 90 дней

### Данные о местоположении
- Приложение запрашивает доступ к местоположению только для работы Bluetooth (требование Android)
- Мы не отслеживаем и не сохраняем данные о местоположении

## 2. Как мы используем данные

- Для работы приложения (учёт товаров, продажи, отчёты)
- Для отправки чеков клиентам через Telegram
- Для отправки push-уведомлений о важных событиях (низкий остаток, завершение доставки)
- Для генерации отчётов и аналитики внутри приложения

## 3. Хранение данных

- Данные хранятся на защищённых серверах
- Пароли хешируются с использованием bcrypt
- API-запросы передаются по зашифрованному каналу (HTTPS)
- Токены аутентификации (JWT) хранятся в защищённом хранилище устройства (EncryptedSharedPreferences на Android)

## 4. Передача третьим лицам

Мы **НЕ** продаём, не передаём и не раскрываем ваши данные третьим лицам, за исключением:

- **Firebase (Google)** — для доставки push-уведомлений (только токен устройства)
- **Telegram Bot API** — для отправки чеков клиентам (только данные чека и chat ID)
- **Sentry (sentry.io)** — для автоматических отчётов о сбоях приложения (тип ошибки, stack trace, версия приложения и устройства, внутренний идентификатор аккаунта; **без** имени, телефона, содержимого экранов и токенов)
- **Национальный банк Таджикистана (nbt.tj)** — для получения курсов валют (мы только читаем публичные данные, ничего не отправляем)

## 5. Безопасность

- Шифрование данных при передаче (TLS/HTTPS)
- Хеширование паролей (bcrypt)
- JWT-токены с ограниченным сроком действия
- Роли и права доступа (владелец, менеджер, кассир)
- Валидация данных на сервере

## 6. Ваши права

Вы имеете право:
- Запросить доступ к своим данным
- Исправить неточные данные
- Удалить свой аккаунт и все связанные данные
- Отказаться от push-уведомлений

Для реализации этих прав свяжитесь с нами: info@itlsolutions.net

## 7. Хранение и удаление

- Данные аккаунта хранятся пока аккаунт активен
- Удалить аккаунт можно прямо в приложении: **Настройки → Удалить аккаунт**, затем ввести пароль для подтверждения. Подробная инструкция — на странице [Удаление аккаунта](delete-account.md)
- Удаление необратимо и выполняется сразу: вместе с аккаунтом удаляются ваши магазины и все данные в них — товары, продажи, клиенты, долги, отчёты. Удаляется и локальная копия этих данных на устройстве
- Если в вашем магазине остались другие сотрудники, удаление не выполнится: сначала удалите их или передайте магазин. Иначе удаление аккаунта владельца лишило бы их рабочего места без предупреждения
- Резервные копии удаляются в течение 90 дней

## 8. Дети

Приложение не предназначено для лиц младше 18 лет. Мы не собираем данные несовершеннолетних.

## 9. Изменения

Мы можем обновлять эту политику. О существенных изменениях мы уведомим через push-уведомление или внутри приложения.
