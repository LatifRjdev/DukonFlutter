# Deep QA — A→Я Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, single-emulator constraint).

**Goal:** Walk every DukonPro feature against the live stack, log findings as PASS/FAIL with severity, repro steps, and screenshots.

**Architecture:** 12 sequential phases. Each phase = one git commit + one markdown report at `qa/2026-05-07-deep/NN-<phase>.md` + screenshot subdir. Per-flow checklist applied across 6 dimensions: CRUD, validation, cross-store leak, plan limits, role-based access, error states.

**Tech Stack:** ADB (mobile UI driving), curl + jq (API verification), Postgres direct queries (state cross-check), logcat (crash detection), API server log tail (401/refresh activity), uiautomator dump (UI tree → tap coordinates).
