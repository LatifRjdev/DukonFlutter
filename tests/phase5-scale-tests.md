## T5.2 API — Поиск по фото

### T5.2.1 Endpoint POST /api/stores/:storeId/products/search-by-image
- [ ] Принимает multipart/form-data с полем `image`
- [ ] Поддерживает JPEG и PNG
- [ ] Ограничение размера: 2MB
- [ ] Ответ: массив {productId, similarityScore, product}
- [ ] Отсортирован по similarityScore desc
- [ ] Порог: similarityScore >= 0.3
- [ ] Максимум 10 результатов
- [ ] Время обработки < 5 секунд (p95)
- [ ] 400 при неподдерживаемом формате
- [ ] 413 при файле > 2MB
- [ ] 503 при недоступности сервиса распознавания

### T5.2.2 Image Embeddings
- [ ] При загрузке фото товара → генерация embedding
- [ ] При обновлении фото → обновление embedding
- [ ] При удалении фото → удаление embedding
- [ ] Vector store индексируется по storeId
- [ ] Поиск выполняется только среди товаров магазина

## T5.4 Edge cases

### T5.4.1 Граничные случаи
- [ ] Товар без фото в каталоге → не найдётся (ожидаемо)
- [ ] Размытое фото → низкий % или "не найдено"
- [ ] Фото не товара (лицо, пейзаж) → "не найдено"
- [ ] Очень тёмное фото → "не найдено" или совет про освещение
- [ ] Фото из галереи (не камера) → работает так же
- [ ] Потеря интернета во время анализа → ошибка + retry
- [ ] 2 одинаковых товара от разных поставщиков → оба в результатах
