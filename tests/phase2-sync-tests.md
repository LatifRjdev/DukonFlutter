## T2.6 Калькулятор закята (F-FIN-006)

### T2.6.1 Активы магазина (автоматические)
- [ ] Стоимость товарных остатков = SUM(quantity × cost_price) рассчитывается автоматически
- [ ] Количество товаров отображается корректно
- [ ] Дебиторская задолженность подтягивается из модуля долгов
- [ ] Наличные в кассе можно ввести вручную
- [ ] При изменении наличных пересчёт происходит мгновенно
- [ ] Нулевые значения отображаются корректно (0 TJS)
- [ ] Badge "Авто" отображается для автоматических полей

### T2.6.1a Личное имущество (множественные позиции)
- [ ] Кнопка "+ Добавить имущество" открывает форму с выбором категории
- [ ] Категории: банковские счета, золото/серебро, наличные, транспорт, недвижимость, инвестиции, другое
- [ ] Каждая позиция имеет название + сумму
- [ ] Несколько позиций в одной категории (например, 3 банковских счёта)
- [ ] Редактирование позиции (карандаш) — изменение названия и суммы
- [ ] Удаление позиции (корзина) с подтверждением
- [ ] Подытог секции отображается справа от заголовка
- [ ] Создание пользовательской категории ("Другое")
- [ ] Все позиции сохраняются между сессиями
- [ ] Валидация: только положительные числа
- [ ] Подсказка: "Личное жильё и личный автомобиль НЕ облагаются закятом"

### T2.6.1b Вычеты (множественные позиции)
- [ ] Долги поставщикам подтягиваются автоматически из модуля поставщиков
- [ ] Кнопка "+ Добавить долг/вычет" для личных долгов
- [ ] Несколько личных долгов (кредит банка, долг знакомому и т.д.)
- [ ] Редактирование и удаление каждого долга
- [ ] Вычеты отображаются красным со знаком минус
- [ ] Подытог вычетов справа от заголовка

### T2.6.1c Итоговый расчёт
- [ ] Облагаемая сумма = Активы магазина + Личное имущество − Вычеты
- [ ] Закят = Облагаемая сумма × 2.5%
- [ ] Пересчёт при изменении любого поля происходит мгновенно

### T2.6.2 Нисаб и хавль
- [ ] Нисаб по золоту: 85г × курс золота
- [ ] Нисаб по серебру: 595г × курс серебра
- [ ] Переключение между методами нисаба работает
- [ ] Индикатор "Превышен" / "Не достигнут" корректный
- [ ] Если нисаб не достигнут — закят = 0, показано предупреждение
- [ ] Дата начала хавля отображается в хиджри и григорианском формате
- [ ] Показано количество оставшихся дней хавля

### T2.6.3 Настройки закята
- [ ] Выбор метода нисаба (золото/серебро) сохраняется
- [ ] Ввод курса золота/серебра вручную
- [ ] Установка даты начала хавля
- [ ] Toggle напоминания работает
- [ ] Включение/исключение категорий товаров из расчёта
- [ ] Toggle каждого вида имущества (вкл/выкл): товары, наличные кассы, банк, золото, наличные дома, инвестиции
- [ ] Toggle дебиторской задолженности (учитывать / нет)
- [ ] Toggle долгов поставщикам (вычитать / нет)
- [ ] Toggle личных долгов (вычитать / нет)
- [ ] Отключённый тип имущества не участвует в расчёте
- [ ] Все настройки сохраняются после перезапуска

### T2.6.4 История и оплата
- [ ] Кнопка "Отметить как оплачено" сохраняет расчёт в историю
- [ ] Снимок (snapshot) данных сохраняется с каждой выплатой
- [ ] История показывает все прошлые расчёты с датами
- [ ] Статусы: "Оплачен" (зелёный) / "Не оплачен" (оранжевый)
- [ ] Можно отметить неоплаченный закят из истории
- [ ] Общая сумма выплат отображается вверху
- [ ] "Поделиться расчётом" генерирует PDF / отправляет в Telegram / SMS
- [ ] Пустое состояние при отсутствии истории

### T2.6.5 Офлайн и edge cases
- [ ] Расчёт работает полностью офлайн
- [ ] При пустом каталоге товаров — стоимость остатков = 0
- [ ] При отсутствии клиентов-должников — дебиторка = 0
- [ ] При отсутствии долгов поставщикам — кредиторка = 0
- [ ] Большие суммы (>1,000,000 TJS) отображаются корректно
- [ ] Дробные суммы округляются до 2 знаков после запятой
- [ ] **Промпты:** `76-zakat-calculator`, `77-zakat-history`, `78-zakat-settings`, `79-dark-zakat-calculator`, `80-dark-zakat-history`
