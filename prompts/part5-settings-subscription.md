## Дизайн-система

### Цветовая палитра
- Primary: #00BCD4 (Бирюзовый), Primary Dark: #0097A7, Primary Light: #B2EBF5

- Background: #F5F5F5, Cards: #FFFFFF, Text: #212121, Text Secondary: #757575

### Типографика
- Шрифт: Inter / SF Pro. H1: 24px Bold, H2: 20px Bold, Body: 16px Regular, Caption: 12px
- Цифры крупные: 32px Bold, средние: 24px Bold

- Радиус: кнопки 12px, карточки 16px, inputs 12px, chips 20px

- Отступы: screen 16px, card 16px, between sections 24px
- Иконки: Outlined/Linear стиль (Lucide/Phosphor), 20-24-32px

## Экраны для генерации

Создай 8 мобильных экранов (iPhone 14 Pro, 393px) для приложения управления магазином "DuckonPro". Интерфейс на русском языке. Стиль: современный, чистый, с бирюзовым акцентом (#00BCD4).

### Экран 1: Настройки (главный экран)
- Header: "Настройки"
- Профиль (карточка сверху): аватар + "Латиф Рахимов" + "Владелец" badge (бирюзовый) + стрелка ">"
- Секция "Магазин":
  - Мои магазины (иконка + стрелка)
  - Продавцы
  - Роли и доступы
  - Скидки
  - Шаблоны чеков
- Секция "Отчёты":
  - Финансовый отчёт
  - История продаж
  - Отчёт по товарам
  - Отчёт по кассирам
- Секция "Интеграции":
  - Telegram-бот (badge "Подключён" зелёный)
  - ККМ/Фискализация
  - Принтер чеков
  - Сканер штрих-кодов
- Секция "Приложение":
  - Уведомления (toggle, включён)
  - Тёмная тема (toggle, выключен)
  - Язык: "Русский" (стрелка)
  - Офлайн-режим (статус: "Синхронизировано ✓")
- Секция "Подписка":
  - Текущий тариф: "БИЗНЕС" + "до 30.03.2026"
  - "Сменить тариф" (стрелка)
- Секция "Поддержка":
  - Справка
  - Связаться с нами
  - О приложении (v1.0.0)
- Кнопка "Выйти из аккаунта" (красная outlined, внизу)

### Экран 2: Профиль пользователя
- Header: "←" + "Профиль" + "Сохранить"
- Аватар (большой, по центру) + кнопка "Изменить фото"
- Поля:
  - Имя: "Латиф"
  - Фамилия: "Рахимов"
  - Email: "latif@example.com"
  - Телефон: "+992 93 123 45 67"
- Роль: Badge "Владелец" (неизменяемый)
- Секция "Безопасность":
  - Сменить пароль (стрелка)
  - Вход по отпечатку (toggle)
- Кнопка "Сохранить изменения" (бирюзовая)

### Экран 3: Мои магазины
- Header: "←" + "Мои магазины" + иконка "+"
- Список магазинов (карточки):
  - 🏪 Основной магазин | Продукты | 3 сотрудника | 245 товаров | Badge "Активен" (зелёный)
  - 🏪 Филиал на Рудаки | Продукты | 1 сотрудник | 120 товаров | Badge "Активен"
  - 🏪 Склад | - | 0 сотрудников | 500 товаров | Badge "Неактивен" (серый)
- Каждая карточка со стрелкой ">" для перехода к настройкам магазина
- FAB "+" добавить магазин

### Экран 4: Настройки магазина
- Header: "←" + "Основной магазин" + иконка "..."
- Фото/лого магазина (с кнопкой изменить)
- Поля:
  - Название магазина
  - Категория (dropdown)
  - Адрес
  - Телефон магазина
  - Валюта (dropdown): TJS / USD / RUB
- Секция "Чек":
  - Название на чеке
  - Адрес на чеке
  - Текст внизу чека: "Спасибо за покупку!"
  - Показывать QR-код (toggle)
- Секция "Опасная зона":
  - Кнопка "Деактивировать магазин" (оранжевая outlined)
  - Кнопка "Удалить магазин" (красная outlined)

- Header: "←" + "Тарифы"

    - 5,000 товаров
    - Telegram-бот
    - Программа лояльности
    - Badge "Ваш тариф" (бирюзовый)
  - **ПРЕМИУМ — 300 сомони/мес**
    - Безлимит
    - Фискализация
    - API доступ
    - Персональный менеджер

- Ссылка внизу: "Сравнить все возможности"

### Экран 7: Оплата подписки
- Header: "←" + "Оплата"
- Выбранный тариф: карточка "БИЗНЕС — 200 сомони/мес"
- Способ оплаты (radio карточки с иконками):
  - 💳 Карта (Корти Милли, Visa, MasterCard)
  - 📱 Мобильный перевод
  - 🏢 В офисе (наличными)
- При выборе "Карта": поля ввода карты (номер, срок, CVV)
- Промокод: input + кнопка "Применить"
- Итого: "200 сомони / месяц" (крупно)
- Кнопка: "Оплатить 200 сомони" (бирюзовая)

### Экран 8: Настройки Telegram-бота
- Header: "←" + "Telegram-бот"
- Статус: Badge "Подключён" (зелёный) или инструкция подключения
- Секция "Подключение":
  - QR-код (для сканирования в Telegram)
  - Или: "Введите код из бота" (input + кнопка "Привязать")
- Секция "Уведомления" (toggles):
  - Ежедневный отчёт: toggle + время "20:00"
  - Низкий остаток товара: toggle
  - Крупная продажа > input "5000" TJS: toggle
  - Просроченный долг: toggle
- Секция "Команды бота" (info карточка):
  - /balance — текущий баланс
  - /today — продажи сегодня
  - /stock АРТИКУЛ — остаток товара
