# DuckonPro — Часть 2: Главная и Товары (8 экранов)

## Дизайн-система

### Цветовая палитра
- Primary: #00BCD4 (Бирюзовый), Primary Dark: #0097A7, Primary Light: #B2EBF5
- Success: #4CAF50, Warning: #FF9800, Danger: #F44336, Info: #2196F3
- Background: #F5F5F5, Cards: #FFFFFF, Text: #212121, Text Secondary: #757575

### Типографика
- Шрифт: Inter / SF Pro. H1: 24px Bold, H2: 20px Bold, Body: 16px Regular, Caption: 12px
- Цифры крупные: 32px Bold, средние: 24px Bold

### Компоненты
- Радиус: кнопки 12px, карточки 16px, inputs 12px, chips 20px
- Тени карточек: 0 2px 8px rgba(0,0,0,0.08)
- Отступы: screen 16px, card 16px, between sections 24px
- Иконки: Outlined/Linear стиль (Lucide/Phosphor), 20-24-32px

## Экраны для генерации

Создай 8 мобильных экранов (iPhone 14 Pro, 393px) для приложения управления магазином "DuckonPro". Интерфейс на русском языке. Стиль: современный, чистый, с бирюзовым акцентом (#00BCD4).

### Экран 1: Главная (Home)
- Header: dropdown выбора магазина слева (иконка магазина + "Основной магазин" + стрелка), иконка колокольчика с красным badge "3" справа
- Tabs период: Сегодня | Неделя | Месяц | 📅 (выбор даты). "Сегодня" активна
- 4 карточки в сетке 2x2:
  - Продажи: 15,420 TJS (стрелка перехода)
  - Себестоимость: 12,100 TJS
  - Расходы: 1,200 TJS (красный текст)
  - Чистая прибыль: 2,120 TJS (зелёный текст)
- Секция "Быстрые действия" — горизонтальный скролл карточек: Остатки, Долги поставщикам (-5,000 красным), Долги клиентов (+12,000 зелёным), Инвентаризация, Заказ поставщику
- Секция "Топ продаж" — горизонтальный список: фото товара + название + "Продано: 45 шт" + "8,100 TJS"
- Секция "Последние продажи" — 2-3 карточки: "Чек #1234 | 14:32 | 3 товара | 1,250 TJS" + ссылка "Все продажи >"
- FAB кнопки над tab bar: "Новая продажа" (Primary, большая) + "Добавить расход" (outlined)
- Bottom Tab Bar: Главная (активна) | Товары | Касса | Финансы | Ещё

### Экран 2: Список товаров
- Header: "Товары" + иконка "..." (меню) + иконка "+"
- Строка поиска: input "Поиск товара" + иконка сканера + иконка фильтра
- Фильтры (chips скролл): Все | В наличии | Заканчивается | Нет в наличии. "Все" активна
- Список товаров (карточки):
  - [Фото] Кофе растворимый | Арт: COFFEE-001 | На складе: 45 шт | Цена: 180 TJS | Себестоимость: 150 TJS
  - [Фото] Сахар 1кг | Арт: SUGAR-001 | На складе: 8 шт (оранжевый — заканчивается) | Цена: 55 TJS
  - [Фото] Чай зелёный | Арт: TEA-002 | На складе: 0 шт (красный — нет) | Цена: 120 TJS
- Sticky footer: "Общая сумма: 125,400 TJS | Себестоимость: 98,200 TJS"
- Bottom Tab Bar

### Экран 3: Карточка товара (детальная)
- Header: кнопка "←" назад + "Товар" + иконки "редактировать" и "..."
- Фото товара (большое, ~40% экрана)
- Название: "Кофе растворимый" + Badge "Активен" (зелёный)
- 4 цветные мини-карточки в сетке 2x2:
  - Цена продажи: 180 TJS (зелёный фон)
  - Себестоимость: 150 TJS (фиолетовый фон)
  - Прибыль: 30 TJS (оранжевый фон)
  - Маржа: 20% (синий фон)
- Секция "Наличие на складе": текущий остаток 45 шт, минимальный 10 шт, progress bar (зелёный)
- Секция "Информация": Артикул: COFFEE-001, Штрих-код: 4601234567890, Категория: Напитки, Поставщик: ООО Оптовик, Единица: шт
- Кнопки внизу (fixed): "Приход" (outlined) + "Продать" (primary filled)

### Экран 4: Добавление товара — Шаг 1 (Основное)
- Header: "←" + "Новый товар"
- Stepper сверху: ● Основное → ○ Цены → ○ Склад (шаг 1 активен, бирюзовый)
- Зона фото: серый placeholder с иконкой камеры, текст "Добавить фото"
- Поля:
  - Название товара * (обязательное)
  - Артикул/SKU
  - Штрих-код (input + кнопка сканера справа)
  - Категория (dropdown со стрелкой)
  - Описание (textarea, 3 строки)
- Кнопка внизу: "Далее" (бирюзовая)

### Экран 5: Добавление товара — Шаг 2 (Цены)
- Header: "←" + "Новый товар"
- Stepper: ✓ Основное → ● Цены → ○ Склад (шаг 2 активен)
- Поля:
  - Закупочная цена * (input с "TJS" справа)
  - Цена продажи * (input с "TJS")
  - Автоматический расчёт: карточка "Маржа: 20% | Прибыль: 30 TJS" (info blue background)
  - Цена оптом (опционально, input с "TJS")
- Кнопки: "Назад" (text) + "Далее" (бирюзовая)

### Экран 6: Добавление товара — Шаг 3 (Склад)
- Header: "←" + "Новый товар"
- Stepper: ✓ Основное → ✓ Цены → ● Склад (шаг 3 активен)
- Поля:
  - Начальный остаток (number input)
  - Минимальный остаток для уведомлений (number input)
  - Единица измерения (chips): шт | кг | л | м
  - Поставщик (dropdown)
- Кнопка: "Сохранить товар" (бирюзовая, на всю ширину)

### Экран 7: Импорт товаров из Excel
- Header: "←" + "Импорт товаров"
- Dropdown: "Выберите магазин"
- Зона загрузки: пунктирная рамка, иконка файла, "Загрузите файл Excel" + "Или выберите файл" (ссылка)
- После загрузки показать: "Найдено 150 строк" (зелёная карточка)
- Секция "Сопоставление столбцов":
  - Наименование * → [Dropdown: Column A]
  - Артикул → [Dropdown: Column B]
  - Штрих-код → [Dropdown: Column C]
  - Количество → [Dropdown: Column D]
  - Цена закупки → [Dropdown: Column E]
  - Цена продажи * → [Dropdown: Column F]
- "При совпадении товаров:" Radio: Обновить | Пропустить | Создать новый
- Кнопка: "Импортировать (150 товаров)"

### Экран 8: Категории товаров
- Header: "←" + "Категории" + иконка "+"
- Список категорий (карточки):
  - 🟢 Напитки (24 товара)
  - 🔵 Бакалея (18 товаров)
  - 🟣 Молочные (12 товаров)
  - 🟠 Кондитерские (8 товаров)
  - 🔴 Бытовая химия (15 товаров)
  - ⚫ Прочее (6 товаров)
- Каждая карточка: цветная иконка + название + количество товаров + стрелка ">"
- FAB кнопка "+" для добавления категории
