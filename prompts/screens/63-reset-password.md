## Забыли пароль — Новый пароль

- Белый фон
- Header: "←" назад + "Новый пароль" (18px SemiBold)
- Иконка щита с галочкой по центру (бирюзовая, 64px)
- Заголовок: "Создайте новый пароль" (24px Bold, по центру)
- Описание: "Придумайте надёжный пароль для вашего аккаунта" (14px, #757575, по центру)
- Поля ввода (outlined, радиус 12px):
  - Иконка замка + "Новый пароль" + иконка глаза справа (toggle видимости)
  - Иконка замка + "Повторите пароль" + иконка глаза
- Индикатор надёжности пароля (горизонтальная полоса под первым полем): красный "Слабый" → оранжевый "Средний" → зелёный "Надёжный". Текущее состояние: зелёный "Надёжный".
- Подсказка: "Минимум 6 символов, буквы и цифры" (12px, #757575)
- Кнопка: "Сохранить пароль" (бирюзовая, на всю ширину)
