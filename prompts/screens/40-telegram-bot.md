Создай мобильный экран (iPhone 14 Pro, 393x852px) для приложения управления магазином "DukonPro". Стиль: современный, чистый, минималистичный.

Дизайн-система: Primary #00BCD4, Success #4CAF50, Background #F5F5F5, Cards #FFFFFF, Text #212121, Text Secondary #757575. Шрифт Inter/SF Pro. Радиус карточек 16px, inputs 12px. Иконки Outlined (Lucide/Phosphor).

## Настройки Telegram-бота

- Фон: #F5F5F5
- Header: "←" назад + "Telegram-бот" (18px SemiBold)
- Статус: badge "Подключён" (зелёный pill) справа от заголовка
- Белая карточка "Подключение":
  - QR-код по центру (100x100px, в рамке)
  - "Или введите код из бота:" + input + кнопка "Привязать" (outlined)
- Белая карточка "Уведомления" (toggles):
  - "Ежедневный отчёт" + toggle (вкл) + время "20:00" (маленький input)
  - "Низкий остаток товара" + toggle (вкл)
  - "Крупная продажа >" + toggle (вкл) + input "5000" TJS
  - "Просроченный долг" + toggle (вкл)
- Белая карточка "Команды бота" (info, голубой light фон):
  - /balance — текущий баланс
  - /today — продажи сегодня
  - /stock АРТИКУЛ — остаток товара
  - Шрифт monospace для команд
