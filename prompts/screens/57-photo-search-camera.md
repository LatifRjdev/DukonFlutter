Создай мобильный экран (iPhone 14 Pro, 393x852px) для приложения управления магазином "DokonPro". Стиль: современный, чистый, минималистичный.

Дизайн-система: Primary #00BCD4, Background #000000, Text #FFFFFF, Text Secondary #B0B0B0. Шрифт Inter/SF Pro. Радиус кнопок 12px. Иконки Outlined (Lucide/Phosphor).

## Поиск товара по фото — Камера

- Фон: чёрный (экран камеры, fullscreen)
- Header (полупрозрачный): кнопка "✕" закрыть (белая) слева + "Поиск по фото" (белый текст, 18px SemiBold) по центру
- Область видоискателя камеры занимает весь экран
- По центру: прямоугольная рамка-фокус (белая, скруглённые углы, пунктирная линия, ~280x280px) с подсказкой внутри: "Наведите камеру на товар" (белый текст 14px, полупрозрачный фон)
- Под рамкой: иконка вспышки (белая, маленькая) — toggle on/off
- Внизу экрана (полупрозрачный тёмный фон):
  - Кнопка "Из галереи" слева (белая outlined, иконка галереи + текст)
  - Большая круглая кнопка съёмки по центру (белый круг 72px с бирюзовым кольцом #00BCD4)
  - Подсказка под кнопкой: "Сделайте фото товара" (12px, белый)
