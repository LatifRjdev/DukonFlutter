Создай мобильный экран (iPhone 14 Pro, 393x852px) для приложения управления магазином "DuckonPro". Стиль: современный, чистый, минималистичный.

Дизайн-система: Primary #00BCD4, Success #4CAF50, Background #F5F5F5, Cards #FFFFFF, Text #212121, Text Secondary #757575. Шрифт Inter/SF Pro. Радиус кнопок 12px, карточек 16px, inputs 12px. Иконки Outlined (Lucide/Phosphor).

## Импорт товаров из Excel

- Фон: #F5F5F5
- Header: "←" назад + "Импорт товаров"
- Dropdown: "Выберите магазин" (outlined, радиус 12px)
- Зона загрузки файла: белая карточка с пунктирной рамкой (бирюзовой), иконка файла Excel по центру + "Загрузите файл Excel" (16px Bold) + "или выберите файл" (бирюзовая ссылка)
- Карточка статуса (зелёный light фон): иконка галочки + "Найдено 150 строк"
- Секция "Сопоставление столбцов" (белая карточка):
  - 6 строк: label слева + dropdown справа
  - Наименование * → [Column A]
  - Артикул → [Column B]
  - Штрих-код → [Column C]
  - Количество → [Column D]
  - Цена закупки → [Column E]
  - Цена продажи * → [Column F]
- "При совпадении:" 3 radio buttons: Обновить (выбран) | Пропустить | Создать новый
- Кнопка: "Импортировать (150 товаров)" (бирюзовая, на всю ширину)
