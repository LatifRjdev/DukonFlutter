Создай мобильный экран (iPhone 14 Pro, 393x852px) для приложения управления магазином "DokonPro". Стиль: современный, чистый, минималистичный.

Дизайн-система: Primary #00BCD4, Background #FFFFFF, Text #212121, Text Secondary #757575. Шрифт Inter/SF Pro. Радиус кнопок 12px, карточек 16px, inputs 12px. Иконки Outlined (Lucide/Phosphor).

## Оплата подписки

- Белый фон
- Header: "←" назад + "Оплата" (18px SemiBold)
- Карточка тарифа (бирюзовый light фон): "БИЗНЕС — 200 сомони/мес" (Bold)
- Способ оплаты (3 radio-карточки, вертикальные, белые с рамкой):
  - Иконка карты + "Карта" + "Корти Милли, Visa, MasterCard" (выбран, бирюзовая рамка)
  - Иконка телефона + "Мобильный перевод"
  - Иконка здания + "В офисе (наличными)"
- Поля карты (появляются при выборе "Карта"):
  - Номер карты (input с маской)
  - Срок (MM/YY) + CVV (2 поля в ряд)
- Input "Промокод" + кнопка "Применить" (маленькая, outlined)
- Итого: "200 сомони / месяц" (20px Bold, по центру)
- Кнопка: "Оплатить 200 сомони" (бирюзовая, на всю ширину)
