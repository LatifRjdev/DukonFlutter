Создай мобильный экран (iPhone 14 Pro, 393x852px) для приложения управления магазином "DukonPro". Стиль: современный, чистый, минималистичный.

Дизайн-система: Primary #00BCD4, Danger #F44336, Background #FFFFFF, Cards #FFFFFF, Text #212121, Text Secondary #757575. Шрифт Inter/SF Pro. Радиус кнопок 12px, карточек 16px, inputs 12px. Иконки Outlined (Lucide/Phosphor).

## Продажа в долг

- Белый фон
- Header: "←" назад + "Продажа в долг" (18px SemiBold)
- Секция "Клиент":
  - Input поиска: иконка лупы + "Поиск клиента" + иконка "+" справа
  - Выбранный клиент (карточка с лёгкой тенью): аватар (инициалы "АК") + "Ахмад Каримов" + "+992 93 123 45 67" + "Текущий долг: 3,200 TJS" (красный)
- Информационная карточка: "Сумма долга: 490 TJS" (бирюзовый фон light)
- "Срок погашения" — date picker input (по умолчанию "13.02.2026", +14 дней)
- "Частичная оплата сейчас" — toggle switch (выключен) + input суммы (disabled)
- "Примечание" — textarea (2 строки, outlined)
- Кнопка: "Оформить в долг" (бирюзовая, на всю ширину)
