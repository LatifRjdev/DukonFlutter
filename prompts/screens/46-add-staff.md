Создай мобильный экран (iPhone 14 Pro, 393x852px) для приложения управления магазином "DuckonPro". Стиль: современный, чистый, минималистичный.

Дизайн-система: Primary #00BCD4, Background #FFFFFF, Text #212121, Text Secondary #757575. Шрифт Inter/SF Pro. Радиус кнопок 12px, inputs 12px, chips 20px. Иконки Outlined (Lucide/Phosphor).

## Добавление сотрудника

- Белый фон
- Header: "←" назад + "Новый сотрудник" (18px SemiBold)
- Аватар placeholder (серый круг 64px, иконка камеры, по центру) + "Добавить фото" ссылка
- Поля ввода (outlined):
  - "ФИО *"
  - "Телефон *" (маска +992, подсказка: "Для входа в приложение")

  - "Магазины" — multiselect chips: "Основной магазин" ✓ (бирюзовый) | "Филиал Рудаки" (серый) | "Склад" (серый)
  - "Оклад" (input + "TJS/мес")
  - "Процент от продаж" (input + "%")
- Info карточка (голубой light фон): "Сотруднику будет отправлен SMS с паролем для входа"
- Кнопка: "Добавить сотрудника" (бирюзовая, на всю ширину)
